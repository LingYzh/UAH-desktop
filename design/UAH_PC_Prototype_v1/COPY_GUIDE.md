# PC 原型文案分层与正式实现清理清单

本文件是正式实现的交接约束。`index.html` 是交互样本，里面的文字不全是产品文案。实现时按下列三类逐条处理，不要整页复制。

| 类别 | 原型中的例子 | 正式实现 |
| --- | --- | --- |
| 用户操作文案 | “新对话”“选择目录”“管理附加目录”“允许本次”“停止” | 保留语义，根据真实能力和操作结果调整措辞。 |
| 真实状态与风险说明 | “没有仓库”“未上报”“等待审批”“原生 Windows 无 Shell 沙盒” | 由会话、文件系统和运行时返回值驱动；条件不成立时不显示。授权影响范围必须留给用户看。 |
| 设计与演示说明 | “原型说明”“示例”“演示”“正式版本应……”“本原型不会……”，固定路径、假账号、假任务和样本回复 | 从正式界面删除；需要的实现约束迁入代码、测试或开发文档。没有数据时显示真实空态。 |

## 源码标记与逐项交接

本轮审查发现原来的标记不完整，已补充 DOM 标记、样本常量说明与源码索引：

| 源码标记 | 处理方式 |
| --- | --- |
| `data-copy-scope="prototype" data-copy-action="remove"` | 删除开发说明或演示入口。运行时适配设计页整体属于此类；实现规则迁入技术文档。 |
| `data-copy-scope="fixture" data-copy-action="replace"` | 保留展示组件，用真实消息、文件、终端、账号与检测结果替换样本值。不是删除整个功能。 |
| `data-copy-scope="mixed" data-copy-action="split"` | 同一段含用户提示和演示说明；逐句拆分，保留真实状态、权限影响、错误原因和操作帮助。 |

`COPY_INVENTORY.md` / `.json` 提供文件、行号与原始源码；每次 `python build.py` 自动重建。`src/data.js` 的种子常量按整块标注，不要求假账号、假路径的每个字符串再加 HTML 属性。`gallery.html` 整页以及场景导览、截图索引、测试用例均是开发材料，不进入正式应用。

这些标记用于人工迁移和复核，**不能作为自动删 DOM 的脚本**。例如消息组件当前装的是样本，正式实现必须保留组件并接真实会话。索引会保守收录混合行，关键词扫描只能发现部分新增遗漏；未命中不等于可直接发布。用户输入、真实模型回复、导入文件和真实工具结果不做关键词过滤。

## 正式实现验收门槛

1. 对索引的每个位置记录“已删除 / 已替换真实数据 / 已拆分”；不能只批量去掉“演示”二字。
2. 测试真实空态、未连接、执行失败和权限受限状态，确保假成功 Toast、假连接状态和样本结果没有进入生产路径。
3. 搜索 `原型|演示|示例|固定样本|正式版|假连接|模拟` 补查新增产品源码；同时人工检查无关键词的固定路径、模型、账号、数字和状态。
4. 运行时支持范围、Ultra 编排、订阅登录和 Windows 隔离能力须经真实接入验证；设计表和示例状态不作为已支持的证据。

重点清理范围：原型导览与场景跳转、模拟的模型和官方账号状态、假 MCP 测试和调用记录、示例终端命令、假浏览器登录、假电脑控制画面、固定会话/文件/计划数据、原型数据重置和“本原型未操作电脑”一类说明。导入导出示例确认不能冒充正式备份。不要把“此处只演示”简单删掉后仍保留可点击的假功能。

权限与诊断文案则要根据真实执行状态重新生成。例如 Codex 沙盒状态需要由官方运行时报告；Claude Code 原生 Windows 不具备其 WSL2 沙盒；UAH 自有引擎只有在 Windows 命令隔离实际工作时才能显示“已隔离”。状态未知时显示“未验证”，并限制相应自动执行能力。对用户有影响的审批、拒绝原因、工作目录、有效读写范围和命令隔离状态属于正式产品信息，不能作为“设计说明”一起删掉。“网页选择器只返回文件夹名称”的原型提示须从正式界面移除，正式 Windows 客户端需显示系统对话框选取并校验后的实际路径。
