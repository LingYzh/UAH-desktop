# 交互与状态图谱

本文件中的箭头描述 UI 转移；它不是已经实现的后端事件协议。场景 ID 对应 `SCENES.json`。

| 起点 | 用户动作 | 结果 | 关键约束 |
|---|---|---|---|
| home | 可选目录 → 填内容 → 发送 | 首次提交并进入聊天，输入区保持在底部 | 空输入不可提交；无目录可聊天；不保存空历史；欢迎区独立滚动 |
| home-ready | 选有活动任务的 Git 主目录 | worktree 冲突确认 | 必须显式选择隔离或共享 |
| folder-conflict | 确认共享风险 | 使用普通目录草稿 | 不提供 worktree |
| chat | 命令摘要 | 原位 command / output | 展开不执行 |
| chat | 编辑摘要 | 原位 Diff | 不打开工具弹窗 |
| chat | 本轮变更文件 | 右栏历史 Diff | 来自轮次快照 |
| diff | 打开当前文件 | 文件页 | 当前文件与历史分离 |
| chat | 分支 | 新分支草稿 | 不自动重跑工具 |
| models-picker | 同引擎模型 | 更新后续请求配置 | 已保存历史不被改写 |
| models-picker | 不同运行时 | runtime-switch → 分支草稿 | 迁移范围确认，旧会话不变 |
| reasoning | 拖滑块 | 下一请求思考强度 | 仅用滑块；档位停靠；已填充区域隐藏刻度点；声明优先，未上报时按协议展示临时默认档位 |
| reasoning | 悬停或聚焦问号 | 当前档位的协议说明 | 临时默认值标注可能被上游拒绝；无详情列表和重置按钮 |
| reasoning | 选 Ultra | 推理强度加主动子代理 / 动态工作流 | Codex 和 Claude Code 按各自运行时映射；普通模型 API 不接收 ultra 字面值 |
| permissions | 只读 / 计划 / 审批 / 自动 | 更新会话权限 | 自动仍受授权范围约束 |
| directories | 主目录菜单 → 管理附加目录 → 系统文件夹选择器添加 / 移除 | 只更新当前会话的文件访问范围；仅主目录是前置条件 | 不手填路径，不伪称限制 Shell 的系统能力 |
| context | 压缩 → 确认 | 更新模拟摘要 | 原始历史保留；仅空闲可操作 |
| composer | 点击单色上下文圆环 / 百分比 | 分色用量详情 | 未知容量不显示虚构百分比 |
| composer | 输入换行 / 添加本地会话引用 / 设置发送键 | 输入框增长至上限后内部滚动 / 引用快照 / 按偏好发送 | 无目录仍可提交普通对话 |
| approval | 展开命令 | 查看请求 | 阅读不批准 |
| approval | 批准 / 拒绝 | 继续模拟任务 / 保留拒绝结果 | 明确入口；停止仍可用 |
| plan-approval | 查看计划 | plan 侧栏 | 不批准执行 |
| plan-approval | 批准执行 | 任务进入运行 | 显式批准 |
| plan | 切换会话 | 当前会话保存的计划文件或“还没有计划” | 运行时计划事件不冒充文件 |
| tasks | 切换会话 | 仅显示目标会话全部后台任务 | 其他任务继续 |
| tasks | 展开 / 筛选 / 停止 | 查看该任务详情或中止态与原因 | 已结束任务仍可查看 |
| exit | 确认退出 | 所有受管活动样本中止 | 恢复不自动续跑 |
| subagents | 选择列表项 → 返回列表 | 当前会话某个子代理的完整只读会话 | UAH 单层；授权回父会话 |
| terminal | 新标签 / 切换 | 各手动终端缓冲区 | 与模型工具记录分开 |
| terminal | 输入安全示例命令 | 本地固定输出 | 其他任意命令不执行 |
| browser | 新标签 / 地址 / 前进后退 | 演示地址与页面状态 | 不加载真实网页 |
| browser | 请求 Agent 操作 | 检查总开关 / Agent / 模式 / 目标 / 租约 | 全部满足后仍需有效观察 |
| browser-auth | 允许此目标 | 当前或记住授权 | 不等于其他网站授权 |
| browser-stale | 重新观察 | 新观察样本 | 不能沿用失效界面坐标 |
| provider-edit | 测试 | 邻近的演示结果 | 不发送网络请求，不保存密钥 |
| runtime-login | 启动官方登录 | 模拟授权流程 | 不接收官方密码 / Token |
| runtime-adapter | 切换权限模式 / 事件类型 | 展示该运行时的映射和有效状态规则 | 无官方审批回传时禁止伪批准 |
| mcp | 项目开关 | 该项目启停 | 其他项目独立，需认证时先授权 |
| mcp-form | 切换 stdio / HTTP 和认证方式 → 保存 | 结构化保存非敏感配置 | Token、环境变量值和请求头值不写入存档 |
| plugin-install | 安装 | 全局安装样本 | 默认不执行任何 hook |
| plugin-detail | 启用项目 | 项目启用 | hooks 仍分别关闭 |
| hook-auth | 确認某项 hook | 该项启用 | 展示命令与范围，不批量连带授权 |
| plugin-detail | 更新 / 卸载 | 预览后更新状态 | 恢复入口，不自动恢复执行授权 |
| memory-edit | 保存 / 删除 | 更新记忆列表 | 纯文本安全渲染 |
| import | 选择更新 / 副本 / 跳过 → 应用 | 校验后写入演示数据 | 可恢复导入前快照，授权字段隔离 |
| export | 选择类别 → 导出 | 下载本原型 JSON | 不含真实密钥；敏感选择再次确认 |
| appearance | 主题 / 减少动效 | 立即生效 | 不重置工具展开和会话状态 |

## 全局可操作入口

侧栏搜索：`Ctrl+K`。新草稿：`Ctrl+N`。收放侧栏：`Ctrl+B`。原型导览：`Ctrl+/`。`Esc` 关闭当前弹层 / 工作面板。发送键可配置为 `Enter`、`Ctrl+Enter` 或 `Alt+Enter`；`Shift+Enter` 换行；输入法组字状态不提交。

右侧面板关闭、固定、标签选择属于当前会话。打开时挤占中央对话区域；窄窗口仍保持分栏，并显示独立的审批 / 停止控制行。长管理页面、代码和 Diff 在各自容器内滚动，不能把整个窗口横向撑开。
