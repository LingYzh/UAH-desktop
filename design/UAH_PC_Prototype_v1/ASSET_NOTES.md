# 资源说明

本包不含任何字体文件，不含 Claude 官方源码、官方截图或专有品牌资源。

`assets/uah-mark.svg` 对应用户仓库既有 UAH 向量标志，仅做格式转写；其路径来源见 `reference/SOURCES.md`。`assets/icons/` 是原型代码中的 66 个 currentColor 线性 SVG 的独立导出，便于组件实现复用。

`OVERVIEW.png` 和 `screenshots/` 是实际原型浏览器截图或其排版合集。截图中显示的系统字体已栅格化，不附带字体文件。图标的独立 SVG 与 HTML 内嵌图标一致；生产使用时应以独立语义名称引用，不复制供应商品牌来表示协议类别。
