# 动效矩阵

权威来源：`src/styles.css`。动效用于表达状态关系，不延迟操作、授权、输入或取消。下表的时长为当前 UI 基准，而不是后端完成延时。

| 变化 | 当前呈现 / 目标 | 保持不变的内容 |
|---|---|---|
| 按钮 hover / active / disabled | 约 150 ms 的背景、颜色和透明度变化 | 点击立即生效 |
| 侧栏收放 | 约 240 ms 宽度过渡 | 当前会话、草稿、工具展开 |
| 快捷功能展开 | 约 220 ms 高度与透明度变化 | 项目列表位置和底部头像锚点 |
| 拖动左右分界线 | 跟随指针，不增加延迟 | 中央阅读空间和最小尺寸 |
| 工具摘要展开 | chevron 约 180 ms；内容就地显示 | 不导航、不执行、不中断文本选择意图 |
| 项目开关 / 设置开关 | 滑块约 170 ms | 权限变化本身立即生效 |
| 菜单 / 对话框 | 小幅淡入，焦点进入当前层 | 背景 inert；Esc；固定确认区 |
| 右侧面板打开 | 约 250 ms 宽度增长，中央对话同步收窄 | 会话所属状态与内容；不覆盖对话 |
| 右侧标签切换 | 约 210 ms 内容入场，面板外框不重播 | 当前标签与滚动状态 |
| 子代理列表 → 只读会话 | 内容小幅入场 | 父会话权限、任务与审批状态 |
| 上下文用量变化 | 单色圆环约 320 ms 更新进度 | 分类颜色只留在详情里 |
| 思考滑块停靠 | 约 210 ms 弹性滑动；跨档需越过中点少许 | 键盘仍可逐档选择；档位值与实际运行时能力一致 |
| Ultra 色条 | 紫色渐变持续流动；覆盖区域的刻度点隐藏 | 减少动效时停用流动效果；不延迟档位提交 |
| 多行输入 | 内容增加时高度增长至 180 px，之后内部滚动 | 发送键设置、附件与正文不丢失 |
| 流式正文 | 按批次追加固定样本 | 不为每一个 token 重新播放入场 |
| 审批 / 失败 / 停止 | 及时显示明确状态 | 不因自动消失提示而丢失错误 |
| 列表编辑 / 移除 | 局部状态刷新 | 不混淆项目启用与全局安装 |
| 主题切换 | 全局 Token 更新 | 不重建会话、展开状态或草稿 |
| 快速重复操作 | 最后一次操作意图生效 | 不累计已失效动画或重复提交 |

## 减少动效

同时支持系统 `prefers-reduced-motion` 和外观页用户开关。启用后过渡 / 动画关闭或降为近零，终态不变，滚动不平滑化。截图用减少动效避免捕获半透明中间帧，不代表未实现动效。

## 正式版另验

实际 GPU 帧率、原生窗口缩放、屏幕阅读器、焦点移动、输入法候选窗、大字号和高 DPI 尚未验收。不得为了“流畅”延迟停止、安全提示、点击确认或吞掉取消错误。
