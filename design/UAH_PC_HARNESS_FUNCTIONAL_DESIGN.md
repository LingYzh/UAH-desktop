# UAH PC 功能基线 · 2026-09-26

此文件补齐原型引用但仓库缺失的功能基线，依据提交 `30432fde35f71aad21eb2cdc42f85142d1089bf8` 的设计规格、修订记录、交接材料与用户本次 review 重建。**这不是找回缺失文件原文的声明。** 用户已选择方案 A，后续明确要求底座样式与图标忠实复用原型。

## 冻结规则

1. 保留 UAH 标志、原 SVG、暖白暖灰、陶土主色和阅读式对话；正式 Vue 实现不能因技术迁移另做视觉方案。
2. 新对话是草稿，首次有效发送建立会话。草稿与历史共用底部输入位置；目录可选，模型必选且可用。无目录不得使用项目文件工具/Shell。
3. 目录、附加目录、输入、工具展开、面板标签、滚动与快照具有明确所有权。附加目录不进入全局默认值，不随新建/分支继承。
4. 右栏分栏而非覆盖。统一宽度预算，必要时压缩导航或临时最大化面板，提供返回对话。停止与审批始终可达。
5. editable draft、saved value 与运行有效配置分离。状态更新保留节点、焦点、选区、输入与滚动；脏表单导航提供保存/放弃/取消。
6. Session → Run → Turn → Message/ToolCall → ArtifactSnapshot 使用稳定 ID。旧轮快照不可被新轮或磁盘覆盖；编辑不重跑，删除不撤销文件，分支记录来源与分支点。
7. 所有启动入口检查能力、真实目录身份和并发租约。共享确认绑定活动集合与环境版本，worktree 必须真实唯一。当前底座保守拒绝冲突，不伪造共享/worktree 成功。
8. 审批绑定 runtime/session/run/turn/request/policyVersion；查看计划或快照不批准。过期、拒绝、中止和已清理请求不得重交。
9. 停止遵循 cancelRequested → stopping → stopped，并等待执行层确认。导航不停止任务，退出取消受管理工作，重启将未完成任务中止，不自动续跑。
10. 文件访问、Shell 隔离、UIA 与进程组清理是不同能力。目录列表、utility process 和 Job Objects 都不得冒充 Shell 沙盒。
11. 供应商/模型用稳定 ID 关联，目录与能力覆盖持久化。停用/缺失时不可新发请求，不隐式换模型；官方订阅凭据不提取成 API Key。
12. 浏览器 profile/tab/会话标签与操作授权分离。登录态是否共享需明确决定，授权不跨会话继承；Cookie/认证头不作为模型观察结果。
13. Windows 控制默认关闭，依次校验总开关、Agent、会话策略、目标授权、父租约和观察代次。子代理不得提高权限。
14. MCP/插件安装、项目启用、hook 授权分离；导入不能赋予执行权、恢复运行或迁移其他设备授权。
15. 导入先校验/预览再原子提交，回滚覆盖全部实体/关系。可恢复导出必须 round-trip；阅读导出明确标示。敏感项默认排除。
16. 系统或应用任一减少动效生效，包括 CSS 无限动画和 JS 滚动。动画可取消；审批、拒绝、停止不得由动画完成回调触发。

## 覆盖与交付边界

完整 UI 细节见 [DESIGN_SPEC](UAH_PC_Prototype_v1/DESIGN_SPEC.md) 与 [COVERAGE_MATRIX](UAH_PC_Prototype_v1/COVERAGE_MATRIX.md)。原型覆盖 Agent、供应商、官方运行时、MCP、插件、记忆、文件、浏览器、终端、任务、子代理、设置和迁移。

原型覆盖不等于正式实现范围。本次底座接本地验证适配器与必要界面；真实模型/CLI、PTY、模型目录、OS 凭据引用、MCP/插件、UIA 动作、进程组、打包签名仍为后续集成工作。
